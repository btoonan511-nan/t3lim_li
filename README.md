# تطبيق تسجيل أعمال الصيانة – سماء الميدان

تطبيق ويب يفتحه المشرف من جواله. يسجّل فيه العمل، والبيانات تنحفظ في جدول Google Sheets والصور في Google Drive.

## الحقول

| الحقل | ملاحظة |
|---|---|
| اسم المشرف | يُحفظ في الجوال، ما يحتاج يكتبه كل مرة |
| نوع الصيانة | وقائية / تصحيحية |
| نوع الرقم + الرقم | أمر عمل / إشعار / طلب |
| وصف العمل | |
| مهندس الكهرباء / القسم | يقترح الأسماء اللي سبق كتابتها |
| الصور | حتى 4 صور (واحدة على الأقل)، تُصغّر تلقائياً قبل الرفع |

كل عمل ياخذ رقم سجل تلقائي (مثل `SM-00001`)، ويسجّل معه تاريخ ووقت الإدخال بتوقيت الرياض. الصور تنحفظ في مجلد خاص لكل عمل، وروابطها تظهر في الجدول.

## خطوات التشغيل (مرة واحدة، دقيقتين من الكمبيوتر)

الجدول ومجلد الصور جاهزين في Google Drive داخل مجلد «نظام أعمال الصيانة - سماء الميدان»، والكود كله في ملف واحد: [`apps-script/app.gs`](apps-script/app.gs) (ونسخة منه في نفس مجلد Drive باسم «الكود الكامل - انسخه كله.gs»).

1. افتح الرابط [script.new](https://script.new) (ينشئ مشروع Apps Script جديد).
2. امسح الموجود والصق محتوى `app.gs` كامل، ثم احفظ (Ctrl+S).
3. **Deploy ← New deployment** ← الترس ⚙️ ← **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy** ثم **Authorize access** واختر حسابك. لو ظهرت «Google hasn't verified this app» اضغط **Advanced ← Go to ...** ثم **Allow** (هذا طبيعي لأن السكربت حقك أنت).
4. انسخ **رابط Web app** (ينتهي بـ `/exec`) وأرسله للمشرفين. من المتصفح يقدر كل مشرف يختار **«إضافة إلى الشاشة الرئيسية»**.

> ورقة «الأعمال» بعناوينها تنشأ تلقائياً مع أول عمل يُسجّل.

> المشرفون ما يحتاجون حساب Google ولا صلاحية على الجدول. التطبيق يحفظ باسم صاحب الجدول.

## للمطورين

`Code.gs` و `Index.html` هي المصدر. بعد أي تعديل عليهم شغّل `python3 build.py` لتوليد `app.gs`.

## رمز دخول (اختياري)

عشان ما يقدر أي شخص يوصله الرابط يسجّل، في أعلى `Code.gs` غيّر:

```js
ACCESS_CODE: '',
```

إلى رمز تختاره، مثل `ACCESS_CODE: '4821',`. بعدها التطبيق يطلب الرمز من المشرف أول مرة ويتذكره.

## تحديث التطبيق بعد أي تعديل

بعد ما تعدّل الكود: **نشر ← إدارة عمليات النشر (Manage deployments) ← ✏️ ← الإصدار: إصدار جديد ← نشر**. الرابط يبقى نفسه.
